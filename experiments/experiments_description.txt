Study Description:
    This study adopts the Transformer hyperparameter configuration from the EEGConformer model, 
    but introduces a modified architectural front-end. We replace the standard backbone with a 
    custom CNN designed to preserve the multi-channel Time-Frequency (TF) representation.
    
    To prepare the data for the Transformer, the representation is tokenized by treating each 
    time-point as an individual token. The corresponding features are generated by concatenating 
    the frequency bins across all channels into a unified embedding vector for that specific 
    moment in time. This approach allows the Transformer to attend to global temporal dependencies 
    while processing the full spectral-spatial context of each time-step. This architecture is 
    evaluated across multiple motor imagery datasets, including BNCI2014_001, BNCI2014_004, 
    and Zhou2016.

Exp_0.1: Within-Subject Cross-Validation
    In this experiment, we make use of five-fold stratified cross-validation, 
    training a new model for each subject.

Exp_0.2: Within-Subject Train/Test (Cross-Validation) & Hold-Out validation Split
    In this experiment, we make use of a hold-out validation split, then applying 
    five-fold cross validation withe the Train/test set.

Exp_0.3: Channels_Frequency Attention 1
    Include learnable channels=frequency attention parameter before conformer tokenization 
    by TransformeEncoder of MTF-C.
    Adopts within-subject cross-validation  paradigm from Exp_0.1.

Exp_0.4: Channels_Frequency Attention 2 
    Same as Exp_0.3, but adopts within-subject cross-validation paradigm from Exp_0.2.

Exp_1.0: LOSO Validation
    Evaluate MTF-C without learnable channels-frequency attention using LOSO validation.

Exp_1.1:

Exp_2.1: Cross-Subject Pre-Training
    We employ a pre-training subset (70% of total subjects data) using the same splitting strategy as in 
    Exp_0.2. 
    
Exp_2.2: Within-Subject Fine-tuning, Fixed Learning Rate
    Then we fine-tune the pre-trained model from Exp_2.1 for 60% of each subject data independently using the same 
    learning rate as during pre-training , and testing on the remaining 40%. 

Exp_2.3: Within-Subject Fine-tuning, Depth Decreasing Learning Rate
    We make use of the pre-trained models and same training splits from Exp_2.1, the  fine-tun on each subject 
    independently decreasing learning rate as we progress in each layer.

Exp_2.4: Within-Subject Fine-tuning, Depth Increasing Learning Rate
    We make use of the pre-trained models and same training splits from Exp_2.1, the  fine-tun on each subject 
    independently increasing learning rate as we progress in each layer.
